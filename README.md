# Basic Chatbot 

This is a simple rule-based chatbot built using Python.

## Features
- Responds to greetings
- Answers basic questions
- Exits on "bye"

## Technologies Used
- Python
- if-elif statements
- loops

## How to Run
1. Run chatbot.py
2. Type messages like "hello", "how are you"
